# Claw-Machine
A claw machine me and my friend made using Arduino

## Creation
Me and a friend made this Claw machine using an Arduino Mega, it's just the mechanical part of it for now and we will add the body later on, but I really need the hours right now haha :P

## Tech
- We used SG90D servos for the xzy movement and an SG90 for the claw motion
- Arduino Mega for control
- The worst wire management maybe ever
- The parts to connect everything are all 3D printed

## AI
No AI was used at all :D
